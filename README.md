## Objetivo

Este proyecto acompaña a personas sin experiencia previa en el manejo de datos
en el aprendizaje de los conceptos y códigos básicos de Python. Cada script
explica cada línea de forma breve y se puede ejecutar directamente desde VS Code,
de modo que el usuario aprenda practicando.

## Contenido

| Archivo | Qué aprenderás |
|---|---|
| `01_operaciones_basicas.py` | Sumar, restar, multiplicar, dividir y otras operaciones |
| `02_estructuras_y_funciones.py` | Listas, diccionarios, bucles y funciones |
| `03_importar_datos.py` | Importar un archivo CSV con pandas |
| `04_limpiar_datos.py` | Duplicados, vacíos, texto y fechas |
| `05_graficos.py` | Gráficos de barras y de líneas |

## Requisitos

- Python 3.10 o superior
- Visual Studio Code con la extensión **Python**
- Git

## Instalación

```bash
git clone https://github.com/[tu-usuario]/python-basico-tutorial.git
cd python-basico-tutorial
python -m venv .venv
.venv\Scripts\activate        # Windows
source .venv/bin/activate     # macOS / Linux
pip install -r requirements.txt
```

## Cómo usarlo

1. Abre la carpeta en VS Code.
2. Abre un archivo de `src/` y léelo de arriba hacia abajo.
3. Ejecútalo con el botón ▶ (arriba a la derecha) o con `python src/01_operaciones_basicas.py`.
4. Cambia los valores y vuelve a ejecutar para ver qué pasa.
